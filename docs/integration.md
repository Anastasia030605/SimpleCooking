# Объединённая версия SimpleCooking

Основа: ветка `feat/recipe-detail-favorites`, которая включает `feat/react-catalog-foundation`. Часть участника 3 подключена к общим компонентам, модели и хранилищу.

## Запуск

Нужны Node.js 22.12+ и npm. `npm ci`, затем `npm run dev`. Проверки: `npm test` и `npm run build`.

## Общие договорённости

- Модель: `src/domain/recipe.ts`.
- Каталог: `/recipes`, фильтруется по названию и сумме `prepTimeMinutes + cookTimeMinutes`.
- Публикация: `/recipes/new`. Форма преобразует значения в `Recipe`, вызывает `saveRecipe` и переходит на `/recipes/:id`.
- Страница рецепта: `/recipes/:id`. Базовые количества ингредиентов не меняются при пересчёте порций.
- Избранное: `/favorites`, отдельное хранилище id рецептов.
- Мои рецепты: `/profile`, фильтрация по `TEST_USER.id`.
- Все экраны используют `simpleCooking.recipes.v1`. Общий каталог не фильтруется по автору.
- Старый прототип участника 3 использовал `simplecooking.recipes.v1` (строчная c). Это отдельный ключ; автоматического переноса старых локальных данных нет, исходные данные не удаляются.

## Публикация

Обязательны название, категория, целое положительное число порций, целые неотрицательные минуты подготовки и приготовления с положительной суммой, минимум один ингредиент и шаг. У числового ингредиента нужны положительное количество и единица измерения. Для «по вкусу» сохраняется `amount: null`. Описание и фотография необязательны; при добавлении фотографии обязательны HTTP(S)-ссылка и alt.

Ошибки чтения и записи хранилища не должны приводить к потере введённых значений. Форма использует общие компоненты Button и Input, подписи полей и текстовые ошибки. При ошибке фокус попадает в первое неверное поле; после добавления ингредиента или шага — в его поле, после удаления — на кнопку добавления. Переход между страницами переводит фокус к основному содержимому.

## Демонстрация сквозного сценария

1. Создать рецепт с категорией, подготовкой 5 минут, приготовлением 15 минут и 2 порциями. Добавить ингредиент с количеством 0,5 стакана, второй ингредиент «по вкусу» и шаги.
2. Опубликовать. Открывается страница участника 2 с сообщением об успешной публикации.
3. Перейти в каталог, найти рецепт по названию и максимальному времени 30 минут. Фильтр 19 минут должен исключить его.
4. Открыть рецепт и увеличить порции до 4. Количество должно измениться с 0,5 до 1, «по вкусу» остаётся без изменения.
5. Добавить в избранное, открыть избранное и перезагрузить страницу. Рецепт остаётся доступен.
6. Открыть «Мои рецепты»: опубликованный рецепт отображается и там.
7. Пройти форму с клавиатуры и проверить видимый фокус. При пустой отправке должны появиться понятные ошибки.
8. Проверить узкий экран и увеличение текста до 200%. Полная ручная проверка экранным диктором остаётся командной задачей.

## Границы версии

Это локальная демонстрация с одним тестовым пользователем. Для реального обмена рецептами между людьми нужны сервер, общая база данных и авторизация. Редактирование, удаление, черновики и перестановка шагов не входят в минимальный сквозной сценарий.
