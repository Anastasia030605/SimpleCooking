# SimpleCooking
Сайт с рецептами, доступный для людей с ограниченными возможностями здоровья. Проект предусматривает понятную навигацию, поддержку экранных дикторов, управление с клавиатуры, настройку размера текста и контрастности. Рецепты сопровождаются пошаговыми инструкциями, списками ингредиентов и описаниями изображений, чтобы готовить было удобно каждому
