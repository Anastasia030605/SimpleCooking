# SimpleCooking

Учебный сайт с рецептами на React + TypeScript. Цель демонстрации 26 октября: создать рецепт → найти в каталоге по времени → открыть → изменить порции → сохранить в избранном → открыть из избранного после перезагрузки.

## Запуск

Нужны Node.js 22.12+ и npm. В репозитории также есть lockfile для pnpm.

```bash
npm ci
npm run dev
```

С pnpm: `pnpm install`, затем `pnpm dev`.

После запуска откройте адрес, напечатанный Vite (обычно `http://localhost:5173`). Проверка сборки: `npm run build`.

Автоматические проверки: `npm test`, проверка TypeScript и сборки: `npm run build`.

Тесты покрывают страницу рецепта участника 2 и общий сценарий: публикация → поиск в каталоге по общему времени → пересчёт порций → добавление в избранное → повторное открытие приложения с сохранёнными данными. Также проверяются ошибки формы и записи, дробные количества, ингредиенты «по вкусу» и разделение общего каталога и собственных рецептов.

## Что уже готово

- React + TypeScript + Vite и маршруты `/recipes`, `/recipes/:id`, `/recipes/new`, `/favorites`.
- Общая шапка, навигация, компоненты `Button`, `Input`, `RecipeCard`.
- Каталог с поиском по названию и фильтром по максимальному **общему** времени (`prepTimeMinutes + cookTimeMinutes`).
- Состояния загрузки, ошибки чтения хранилища и пустой выдачи.
- Общий контракт рецепта и хранилище `localStorage`; новые рецепты появляются в каталоге сразу после `saveRecipe` и остаются после перезагрузки.
- Страница рецепта с пересчётом порций, шагами и избранным; отдельный экран избранного.
- Форма публикации `/recipes/new`: название, категория, время подготовки/приготовления, порции, ингредиенты и шаги. Описание и фотография необязательны; для фотографии требуется alt. Поддержаны дробные количества и «по вкусу».
- Раздел `/profile` показывает рецепты тестового пользователя, общий каталог — рецепты всех авторов в текущем хранилище.

## Контракт для команды

Типы `Recipe`, `Ingredient`, `Step`, `User` и тестовый пользователь находятся в `src/domain/recipe.ts`. Каталог использует `Recipe.id`, `title`, `category`, `description`, `prepTimeMinutes`, `cookTimeMinutes`, `baseServings` и `image`. Для пересчёта порций нужны `Ingredient.amount`, `unit` и `Recipe.baseServings`.

Хранилище находится в `src/data/recipeStore.ts`:

```ts
getRecipes(): Recipe[]
getRecipeById(id: string): Recipe | undefined
saveRecipe(recipe: Recipe): void
subscribeToRecipes(listener: () => void): () => void
```

Ключ `localStorage`: `simpleCooking.recipes.v1`. При отсутствии сохранённых данных каталог показывает три примерных рецепта. `saveRecipe` сохраняет новый рецепт вместе с ними и уведомляет каталог в этой вкладке; событие `storage` обновляет другие вкладки. Если браузер не даёт читать или писать хранилище, функция выбрасывает ошибку; интерфейс должен показать её пользователю.

## Подключение части участника 3

Форма находится в `src/features/recipes/CreateRecipePage.tsx`, валидация и преобразование данных — в `recipe-form.ts` рядом с ней. Форма использует общие `Button` и `Input`, тип `Recipe` из `src/domain/recipe.ts` и `saveRecipe` из общего хранилища. Публикация сразу открывает полноценную страницу участника 2. Отдельного хранилища рецептов у формы нет.

[Инструкция по проверке и ограничениям](docs/integration.md).

## Ограничения демонстрационной версии

Данные сохраняются в localStorage конкретного браузера. Обмена рецептами между устройствами пока нет: нужен сервер с общей базой данных. Используется один тестовый пользователь; настоящая авторизация отсутствует. Редактирование, удаление и черновики отложены. Для публикации сайта на хостинге нужен SPA fallback на `index.html`, чтобы прямые ссылки `/recipes/:id` работали после перезагрузки.

## Доступность

Есть ссылка пропуска навигации, видимый фокус, подписи полей, текстовые ошибки и семантические элементы. Каждый участник проверяет клавиатуру и увеличение текста на своих новых экранах.

## Настройки отображения

На всех страницах доступна панель «Настройки отображения»: обычный текст, крупный (125%), очень крупный (200%) и контрастная чёрная тема со светлым текстом. Выбор сохраняется в `simpleCooking.display.v1`, настройки можно сбросить отдельно от рецептов. Если сохранение заблокировано, выбранный режим всё равно применяется в текущем сеансе. Настройки управляются с клавиатуры; радиокнопки размера переключаются стрелками.
